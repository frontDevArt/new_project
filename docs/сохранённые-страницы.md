# Сохранённые страницы для отладки парсера

Парсер отлаживается на страницах с диска, а не походом на сайт: так правку
видно сразу, и Cloudflare не считает нас за робота. Реализация `files` порта
`Fetcher` читает те же пути тем же кодом, каким читала бы ленту.

Страницы кладутся в папку `scrape.pages_dir` (по умолчанию `data/pages/`).
Папка `data/` в `.gitignore` — после клонирования её нужно создать самому.

## Имя файла

Оно получается из пути URL: слеши заменяются на дефисы.

```
https://www.list.am/ru/category/60     ->  category-60.html
https://www.list.am/ru/category/60/2   ->  category-60-2.html
https://www.list.am/ru/category/60/3   ->  category-60-3.html
```

## Как сохранить

Открыть страницу в браузере, `Ctrl+S`, тип «Веб-страница, только HTML».
Картинки и стили не нужны — парсер читает разметку.

## Как переключить прогон на диск

В `config/dev.yaml`:

```yaml
scrape:
  kind: files
  pages_dir: ./data/pages
```
