# M0: парсер карточек и обход категории — план

> **Для исполнителя:** шаги отмечаются чекбоксами (`- [ ]` → `- [x]`) по мере выполнения.
> Порядок задач менять нельзя: каждая следующая опирается на результат предыдущей.

**Цель:** закрыть этап M0 — получить базу на 20 000 объявлений и `.xlsx`, который можно открыть и отсортировать.

**Подход:** парсер пишется и отлаживается на сохранённых страницах (`scrape.kind: files`), сайт не трогаем.
Когда разбор подтверждён на фикстурах — включаем `playwright`, идём 20 страниц, смотрим статистику,
потом полный обход. Каждая задача заканчивается проверяемым результатом.

**Стек:** Python 3.12, BeautifulSoup + lxml, SQLite, openpyxl, pytest.

**Спека:** `list.am → заявки покупателей MVP-спека и роадмап.md`

## Что уже готово (до этого плана)

Каркас, порты, миграция `001_initial.sql`, `doctor`, `export`, три реализации `Fetcher`
(`http`, `playwright`, `files`), контрактные тесты. База пустая: `listings 0`, `runs 0`.
Парсера карточек и команды обхода нет — это и есть содержание плана.

## Общие ограничения (из спеки, нарушать нельзя)

- Пагинация только путевая: `/ru/category/60/2`. Query-параметры фильтров (`n=`, `price1=`, `rooms=`, `srt=`, …) запрещены в `robots.txt`.
- Пауза между запросами — из конфига, по умолчанию 1.5 с. Никаких параллельных пачек.
- Все отметки времени в UTC, пути относительные от корня проекта.
- Ни один путь, ключ и идентификатор не зашит в код — только конфиг и `.env`.
- Парсер не падает из-за отсутствия любого поля в карточке: нет поля — `None`.
- Схема базы меняется только новой версионированной миграцией.
- Телефоны на M0 не трогаем вообще.

## Разбор вёрстки (снято с живых страниц 21.09.2026)

Одна страница ленты — 105 ссылок `/item/<id>`, из них 9 в блоке `#tp` («Топ объявления»).
Топ-блок повторяется от страницы к странице и не подчиняется сортировке по дате, поэтому
**он исключается**: парсим `#contentr` без поддерева `#tp` → 96 карточек на страницу.

| Поле | Откуда берётся | Пример |
| --- | --- | --- |
| `id` | `/ru/item/(\d+)` из `href` | `24221707` |
| `url` | абсолютный адрес из `href` без query | `https://www.list.am/ru/item/24221707` |
| цена + валюта | `.category-data-list-card__amount`, символ внутри `.category-data-list-card__currency` | `290,000` + `$`; `33,912,000` + `֏`; встречается `€` |
| `title` | `div.l` | `2-комн. квартира в новостройке на ул. Ачаряна в Аване, 56 кв.м., 7/18 этаж` |
| `rooms`, `area`, `floor`, `floors_total` | `div.at` (первый, не `__location`) | `2 ком., 56 кв.м., 7/18 этаж` |
| `district` | `.category-data-list-card__location` | `Кентрон`, `Арабкир`, `Аван` |
| `seller_type` | `span.ge3` = `Агентство` → `agency`; значка нет → `owner` | 183 агентства из 210 карточек |
| `verified` | `span.pr93`: класс `unverified` → `False`; `Проверено по кадастру` / `Собственность подтверждена` → `True` | |
| `new_build` | в заголовке `в новостройке` | |
| `street` | из заголовка: `на ул. X` / `на пр. X` / `на ул-е X` | `Ачаряна` |

Значки `po77` (`Срочно`, `Супер цена`, `Красивый вид`) — маркетинг продавца, не сохраняем.

| --- | --- |

| `--dry-run` | 192 карточки разобраны, в базу и в хранилище не ушло ничего |

Что стоит знать про прогон:

Курс берётся один раз в начале и попадает в строку `runs` — старые цифры
воспроизводятся. Пересчёт валют делает прогон, не парсер: у парсера курса нет.
Евро курс не покрывает, поэтому у единственной евровой карточки `price_usd` и
`price_per_sqm` пустые — это видно в базе и честнее выдуманного курса.

Пауза между запросами живёт в адаптере `Fetcher` (`scrape.delay_seconds`), поэтому
цикл обхода её не дублирует и параллельных запросов не появляется по построению.

Страница, которая не отдалась, останавливает прогон и считается ошибкой: счётчик
`runs.errors` и текст в `runs.notes`, код возврата 1. На снимке из двух страниц это
видно как «страница 3 не получена» — пагинатор второй страницы честно зовёт дальше,
а третьей на диске нет. На живом прогоне задачи 3 такой строки быть не должно.

Курс на сохранённых страницах берётся тем же адаптером `rate_am`: снимок rate.am
лежит рядом с лентой в `data/pages/` под именем, которое даёт `FilesFetcher`
(`ru-armenian-dram-exchange-rates-banks-cash.html`). Отдельного «тестового» курса
в коде нет.

`config/dev.yaml` оставлен на `scrape.kind: files` — задача 3 начинается с того, что
его нужно переключить обратно на `playwright`.
